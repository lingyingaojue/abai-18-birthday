# 阿白不是白 · 18岁生日快乐 🎂

一个写给 **阿白不是白** 的 18 岁生日祝福网页。

- 生日：8 月 28 日
- 纯 HTML / CSS / JavaScript，无需构建
- 包含倒计时、气球、蛋糕、彩带、点击庆祝等小彩蛋
- 可部署到 GitHub Pages / Vercel / Netlify 等静态托管

## 本地预览

直接用浏览器打开 `index.html` 即可。

也可以启动一个本地服务器：

```bash
npx serve .
```

## 部署到 GitHub Pages

1. 把本仓库推送到 GitHub
2. 在仓库 Settings → Pages 中，选择 `main` 分支的 `/ (root)` 目录
3. 完成后访问 `https://<你的用户名>.github.io/abai-18-birthday/`

祝你 18 岁生日快乐！🎉
